#  Dual Gradient Pruning
This repository provides an implementation of [AAAI 24] Revisiting gradient pruning: A dual realization for defending against gradient attacks. 
The privacy evaluation component is built upon the Breaching framework(https://github.com/JonasGeiping/breaching）, while the model training component is adapted from the Gradient Quantization framework (https://github.com/xinyandai/gradient-quantization/tree/master).
